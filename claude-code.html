指令 / 語法用途與差異範例
claude
CLI		開啟互動會話。claude
claude "query"
CLI		帶入初始提示並開啟互動會話。claude "explain this project"
claude -p "query"
CLI		單次查詢並退出。claude -p "explain this function"
cat file | claude -p "query"
CLI		將檔案內容經 stdin 交給 Claude 處理。cat logs.txt | claude -p "explain"
claude -c
CLI		接續目前目錄最近對話。claude -c
claude -c -p "query"
CLI		以非互動方式接續最近對話。claude -c -p "Check for type errors"
claude -r "<session>" "query"
CLI		恢復指定 ID 或名稱的會話。claude -r "auth-refactor" "Finish this PR"
claude update
CLI		更新到最新版本。claude update
claude gateway
CLI		啟動供管理員部署的自架 gateway；需 --config gateway.yaml。claude gateway --config gateway.yaml
claude install [version]
CLI		安裝或重裝原生執行檔，可指定 stable、latest 或版本。claude install stable
claude auth login
CLI		登入；--email 預填、--sso 使用 SSO、--console 使用 API 計費帳號。claude auth login --console
claude auth logout
CLI		登出帳號。claude auth logout
claude auth status
CLI		以 JSON 顯示認證狀態；--text 改為文字，退出碼 0 已登入、1 未登入。

SOURCES & SCOPE

來源與完整性範圍

以 Anthropic 官方文件為準，逐項撰寫用途摘要；命令列語法保留英文。每節表格列出該文件的全部命令條目，MCP 與 Plugin 子指令另行補充；未收錄未公開的內部命令，也無法枚舉個別專案自行新增的 skills、plugins 或 MCP prompts。

會話輸入 / 查看當下可用清單；自訂指令可能來自 .claude/skills/<name>/SKILL.md、舊式 .claude/commands/ 或 plugin。部分內建命令因環境限制不會顯示；請對照來源的版本與可用性說明。

CLI 診斷可先執行 claude --version、claude --help；子指令選項可用 claude mcp --help、claude plugin --help 查詢。官方特別註明 --help 並不列出所有已公開旗標。--help / -h 是查詢說明的通用選項，未列入官方旗標主表。

容易混淆：claude agents 管理背景會話，/agents 提示管理 subagent 設定；/branch 分支對話，/fork 複製到背景，--worktree 隔離 git 工作目錄；/loop 是本次會話排程，/schedule 是雲端 routine。
